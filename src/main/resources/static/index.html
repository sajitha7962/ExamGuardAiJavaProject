Engineered for Modern Academic Excellence

Complete end-to-end examination ecosystem for colleges, departments, and universities.

Role-Based Access Control

Independent, securely authenticated portals for University Administrators, Course Professors, and Enrolled Students with strict server-side boundary enforcement.

Face Biometric Enrollment

Consent-driven facial geometry capture before exam clearance. Automatic identity verification and continuous visibility monitoring prevent proxy examinations.

Server-Side Deadline Enforcement

Never trusts student browser clocks. Centralized server-side deadline calculation auto-submits answers at expiration and protects against local clock manipulation.

Real-Time Live Monitoring

Professors view synchronized live tiles of all examinees via WebSocket with active camera status, tab-switch logs, risk scores, and remote warning capability.

Multi-Type Question Bank

Build comprehensive evaluations with MCQs, multi-select, true/false, fill-in-the-blanks, short answer, and long descriptive questions with automatic or manual grading.

Interruption Recovery

Seamless resilience against network drops. Every answer is persistently committed to MySQL so students resume their session without losing progress or time.

The Examination Lifecycle

Designed for high academic standards and fairness.

1

Exam Creation Wizard

Professor configures basic parameters, student eligibility, imports questions, and enables proctoring restrictions.

2

Biometric Readiness

Student completes face enrollment, grants webcam permissions, and passes the system compatibility checklist.

3

Proctored Session

Student enters the distraction-free exam room. Answers are auto-saved while proctoring events stream live to the professor.

4

Evaluation & Release

Objective questions are scored automatically. Professor grades descriptive questions and releases audited results.

INTELLIGENT INTEGRITY

Multi-Layered Browser Proctoring

ExamGuard AI implements non-invasive, privacy-conscious monitoring using standard web standards without requiring proprietary third-party software installations.

  • ✔ Tab & Window Tracking: Page Visibility and focus detection alert professors if students leave the examination.
  • ✔ Face Absence & Multi-Face Detection: Identifies when the student leaves the frame or an unauthorized person enters.
  • ✔ Authorized Screen Capture: User-authorized screen stream monitoring ensures academic integrity.
  • ✔ Auditable Incident Review: All events are logged with timestamps, severity, and professor review status.
